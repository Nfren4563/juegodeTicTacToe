## Descripción

Este proyecto es una versión del juego Tic-Tac-Toe, también conocido como tres en raya o gato.

Fue desarrollado en Java utilizando Java Swing para crear la interfaz gráfica.

El juego permite que dos jugadores utilicen la misma computadora y se turnen para colocar los símbolos `X` y `O`.

## Funciones principales

- Tablero de 3 × 3.
- Juego para dos personas.
- Cambio automático de turnos.
- Detección del ganador.
- Detección de empate.
- Botón para reiniciar la partida.
- Mensajes con el resultado del juego.

## Requisitos

- Java JDK 8 o superior.
- Un sistema con interfaz gráfica.
- IntelliJ IDEA, NetBeans o Eclipse, opcionalmente.

## Cómo descargarlo

```bash
git clone https://github.com/Nfren4563/juegodeTicTacToe.git
cd juegodeTicTacToe
```

## Cómo ejecutarlo

Compila los archivos:

```bash
javac -d out TicTacToe/*.java
```

Ejecuta el juego:

```bash
java -cp out TicTacToe.InterfazTicTacToe
```

También puedes abrir el proyecto en IntelliJ IDEA y ejecutar `InterfazTicTacToe.java`.

## Cómo jugar

1. El jugador `X` comienza.
2. Haz clic en una casilla vacía.
3. Después será el turno del jugador `O`.
4. Gana el primer jugador que complete una fila, columna o diagonal.
5. Presiona **REINICIAR** para jugar otra vez.
